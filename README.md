# Supply Chain LinkedIn Posts

Automation helper for **Mohammed Omar** — short LinkedIn posts on logistics & supply chain, with a topic image each run.

## What this repo is for

- Store post drafts and images generated by the Cursor automation
- Keep theme history so posts don’t repeat
- Act as the GitHub repo linked to the Cursor Cloud Agent / Automation

## Setup (do once)

### 1) Push to your GitHub repo
Repo: https://github.com/saqeromar45/LinkedIn-Agent_55_2.git

From this folder (already initialized with `origin`):
```bash
git push -u origin main
```

If GitHub asks for login, use a Personal Access Token as the password.

### 2) Link the repo to the Cursor Agent environment
1. Open: https://cursor.com/dashboard/cloud-agents/environments/e/ce61b203-8f40-11f1-a7d1-d6b4613131ce
2. Attach this GitHub repo to the environment
3. Re-run or update the automation so it starts from that environment

### 3) Connect LinkedIn to the automation
1. Open: https://cursor.com/automations/c1dab793-8f40-11f1-a7d1-d6b4613131ce
2. Add a **LinkedIn** delivery action (or the social publish action available in your plan)
3. Authenticate with your LinkedIn account
4. Update the automation prompt to publish the short post + image via that action

## Post format

- Short English LinkedIn copy
- Strong hook + 1–2 paragraphs + light CTA
- One topic-specific image per post
- Avoid repeating recent themes (see `posts/themes.md`)

## Folder layout

```
posts/          # dated drafts (copy + image path)
posts/themes.md # used / unused themes
assets/         # generated images
PROMPT.md       # automation prompt to paste into Cursor
```
